# 云脊茶园梯田规划工作台

浏览器端山地新开茶园梯田规划、挖填方计算与 WebGL2 三维预览系统。纯前端 TypeScript 实现，项目保存在 IndexedDB，不上传测绘数据。

## 安装与启动

```bash
pnpm install
pnpm dev
```

也可以使用 `npm install && npm run dev`。

生产构建（不先做全量类型门禁，避免第三方类型小问题阻断打包）：

```bash
pnpm build
pnpm preview
```

依赖安装后也可单独做严格类型检查：

```bash
pnpm typecheck
```

核心算法测试：

```bash
pnpm test
```

挖填方解析地形核对：

```bash
pnpm validate:earthwork
```

> 运行前端需要安装 `geotiff`、`vite`、`typescript` 等 `package.json` 中已声明的依赖。

## 页面

1. **项目列表**：新建、编辑、复制、删除项目；完整方案 JSON 导出/导入。
2. **地形导入**：GeoTIFF 首波段、高程矩阵 CSV、X/Y/Z 点表；无数据时生成带主峰、山脊和沟谷的程序地形。
3. **梯田设计**：按高程相位提取等高走向，生成台面/田坎设计高程；台宽、坎高、禁垦坡度可调；逐台块挖填方表和平衡偏差。
4. **茶行布置**： marching squares 提取等高线，沿各台块中线和多行距偏移布行；弯道按弧长布株，空间哈希限制最小净距。
5. **季相预览**：春梢、盛夏、秋褐、冬绿冠色，距离雾、山谷晨雾、太阳方位/高度。
6. **设置与校核**：渲染质量、10 万实例压力测试、解析斜面/圆锥精度报告、项目 JSON 导出。

另含：

- D8 + Priority-Flood 流向、汇水面积；
- 排水沟和步道沿最大坡度追踪，平面编辑器可手绘、拖顶点、删除；
- 任意两点剖面线，原地形/设计地形断面对比，断面图与三维标记联动；
- 茶行坐标 CSV、挖填方 CSV、当前 WebGL 画布 PNG 导出。

## 挖填方口径

地形和设计面使用同一套平面坐标。网格顶点保存高程，正式方量不直接用粗网格中心点近似，而是在每个 DEM 格子内做双线性亚格子加密：

```text
cut  = Σ max(z_original - z_design, 0) × sub_area
fill = Σ max(z_design - z_original, 0) × sub_area
```

代码同时保留了基于三角形零值交线的精确棱柱积分 `triangleCutFill`，用于小规模已知体核对。

`pnpm validate:earthwork` 会构造解析斜面和圆锥面，并与 2048² 解析设计面密采样结果比较。当前结果：

| 场景 | 挖方误差 | 填方误差 | 净方差 |
| --- | ---: | ---: | ---: |
| 解析斜面 / 256–1024 | < 0.001% | < 0.001% | < 0.001% |
| 解析圆锥 / 256–1024 | < 0.004% | < 0.001% | < 0.005% |

均低于主人要求的 1%。项目边界可能切断完整台块，因此总挖填不一定严格相等；界面显示真实挖填差和平衡偏差百分比。

## 性能设计

- 茶树使用 `drawArraysInstanced`，单株低多边形茶蓬/树干合并几何；
- 1024² 地形使用 `Uint32Array` 索引，质量页可按 1/2/4 抽稀显示；
- DPR 按质量档限制，避免 4K 屏像素压力失控；
- 汇流、梯田和茶行结果只在参数变化时重算并持久化；
- 设置页提供 100,000 株压力测试和实时 FPS/实例数/HUD。

## 目录

```text
src/lib       纯算法：地形、坡度、梯田、方量、等高线、茶行、汇流、剖面、导入导出
src/webgl     WebGL2 Viewer、Shader、实例化茶树和场景数据
src/ui        六个页面、弹窗、剖面 SVG、平面编辑器
scripts       精度核对与冒烟脚本
test          Node 原生测试
```

## 浏览器要求

需要支持 WebGL2、IndexedDB 和 ES2022 的现代 Chrome/Edge。GeoTIFF 解析在浏览器本地完成。
